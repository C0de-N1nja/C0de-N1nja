## 🔧 Featured Project

### 🏗️ VerifyChain: Multi-Sig Governed, Merkle-Proof Universal Credential Verification System
**A credential verification system built to address fake degree fraud in Pakistan.**

- Backend built with **Node.js** and **Ethers.js**, handling all blockchain read/write operations
- Smart contracts written in **Solidity**, tested with **Foundry**, deployed on **zkSync**
- Merkle Tree bulk issuance registers an entire batch of credentials in a single on-chain transaction
- Multi-Signature governance requires a 2-of-3 board quorum for institutional onboarding
- **Issuer Portal** where institutions issue single or bulk credentials via MetaMask
- **Verifier Portal** where employers verify any degree instantly by scanning a QR code, no wallet needed
- Certificate PDF with embedded QR verification block, auto-delivered to students via email

**[View Repository →](https://github.com/C0de-N1nja/VerifyChain)**
